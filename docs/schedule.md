# Турниры и календарь

Раздел `/tournaments` использует существующий API-клиент (`/api`, JWT из текущей
сессии). Все ID модуля остаются строками, включая Uint64 больше MAX_SAFE_INTEGER.

## Рабочий сценарий

1. В «Команды и города» добавьте справочники, если они пусты.
2. Создайте турнир вручную или через шаблон. Шаблоны: круговой, одинарное/двойное
   выбывание, две группы с плей-офф. Расширенный редактор поддерживает JSON-схему.
3. Для ручного турнира добавьте этапы и пустые слоты. Укажите источники квалификации
   «Из группы», затем сформируйте календарь. Для шаблона эти действия автоматические.
4. На вкладке «Участники» назначьте команды. На вкладке «Календарь» внесите оба счёта.
5. Для круговых этапов смотрите «Таблица». На вкладке «Сетка» нажмите «Заполнить по
   результатам». Ничья серии допускает выбор победителя по дополнительному регламенту.

Доступны изменение дат/городов матчей, параметры турнира и этапов, фильтры,
экспорт календаря/шаблона, ручное назначение незаполненных слотов сетки.
Удаления подтверждаются в диалоге; ошибки сервера остаются в форме, введённые
значения не теряются. Повторная отправка во время сохранения блокируется.

## Существующие ограничения сервера

- Команды, города, календарь и шаблоны сохраняются в YDB. Используемые
  города и команды защищены от удаления; команда требует существующий город.
- Сгенерированный календарь нельзя пересоздать или удалить отдельными матчами.
  Турнир с матчами удалить нельзя. Использованные результаты защищены от правок.
- При полном равенстве критериев в группе автоматическая квалификация не выбирает
  команду произвольно; доступно ручное назначение в сетке.
- Переопределить уже заполненный слот без отката зависимостей сервер не позволяет.

## Проверки

```sh
npm run build
node --test tests/schedule-template.test.mjs  # Node 24 с поддержкой TypeScript
```

Отдельно проверяется реальный путь API → YDB (шаблон, календарь, жеребьёвка),
а в браузере — авторизация, маршруты, формы, счёт, таблица и сетка.
